# Library Inventory Manager - 

A simple command-line Library Management System built using Python OOP concepts.

## Features
- Add books
- Issue and return books
- Search by title or ISBN
- Save data automatically to JSON file
- Proper error handling and logging

## How to Run
1. Open terminal in project folder
2. Run: `python -m cli.main`
